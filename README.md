# Cold & Quiet Cryostat Model

The repository contains a STEP model of the custom cryostat used in the work [Cryogenic geometric anti-spring vibration isolation system](https://iopscience.iop.org/article/10.1088/1361-6501/ae5404/meta).

An online 3D render can be accessed through [this link](https://3dviewer.net/#model=https://raw.githubusercontent.com/mpa139/Cold_and_Quiet/refs/heads/main/cryo-design.step).

This fridge has been developed by the [Allan Lab](https://www.allanlab.org/) and the FMD, with many of the authors involved. H.S.M. Bohemen and K. van Oosten led the effort to build the fridge. The idea originates from the [Garry Steele lab](https://steelelab.tudelft.nl), which kindly shared drawings.
